# 小红书商单前期谈判技巧

> 适用范围：**接单前**的谈判环节，重点是小红书平台合作（蒲公英报备体系）。
> 本 Skill 原本的流水线从“已有 Brief”开始；本篇补上 Brief 之前的那一关——
> 谈判谈下来的条款，正是后面基础条款 9 项拆解的输入。谈判没谈清的，进“待确认问题”，不报价、不开写。
>
> 方法论框架来源：Jessi Cao（@JessiCao_JC）的文章《小红书接广到底怎么运转？粉丝门槛、报价、返点和“水上水下”，一次讲清楚》
> （https://x.com/JessiCao_JC/article/2114541892734173487），由本仓库维护者整理、蒸馏。
> 本文是二次整理，不是原文转载；平台规则以小红书官方最新口径为准，文中提到的门槛与费率请以申请页面和结算明细核对。

## 谈判第一原则：先问清，再报价

收到询价先别报数字。先搞清楚四件事，再决定报多少、接不接：

1. **拍什么**：图文还是视频、几篇、哪些画面必须有；
2. **给谁用**：只发自己账号，还是品牌还要拿去投流、二改、长期使用；
3. **改几次**：修改轮次是多少，什么算一次修改；
4. **钱怎么到账**：订单金额、返出部分、平台费税费、谁付款、什么时候结。

信息不齐就报价，等于在不知道成本的情况下定价。产品与自己内容根本不贴合的，尽早拒绝，
不要为了一单让账号突然推荐自己没用过的东西。

## 门槛认知：1000 粉只是准入，不是接单保证

- 蒲公英博主入驻有门槛（官方指南列出的条件包括实名、成年、粉丝量、专业号升级、无违规等），
  达到门槛只代表“能用官方合作功能”，不代表自然有商单。
- **两种买卖要分开报**：一种是品牌买你的拍摄能力（素材制作），一种是品牌买你账号的传播价值（发笔记）。
  前者按制作成本算，后者还要算账号价值，不能只按粉丝数混在一起报价。
- 没到门槛也不用乱接合作证明自己。先看清邀约性质：免费试用、实物置换、现金发布，还是购买素材。
  “寄你一份产品”不等于没有交付要求——要不要发笔记、什么时候发、要不要审稿，都要问。
- 账号还小时，简介写清楚比堆“可接合作”有用：让陌生品牌一眼看出你的内容适合什么产品、
  产品应该放进什么场景。

## 合作资料：一页纸，五项就够

谈判前先备好一页合作资料，谈判时直接发过去，省掉来回问答：

| 项 | 写什么 |
|---|---|
| 账号定位 | 面向谁，主要解决什么问题 |
| 近期表现 | 最近 10–20 篇笔记的数据区间和中位数，注明统计时间 |
| 代表作品 | 选三篇，分别展示场景、讲解能力、真实互动 |
| 可提供内容 | 图文、视频、素材拍摄等，只写自己真正能交付的 |
| 合作条件 | 档期、基础报价包含什么、哪些需求另议 |

- 数据少就如实写少，不拿最高一篇假装平均水平。
- 自然流量和投流带来的数据分开写，否则对方会按一个你无法重复的结果期待下一单。
- 粉丝画像有后台数据就标清来源；没有，就别从评论区几个人推算成消费能力。

## 对接人：三个问题，确认三个角色

日常询价里“PR”常被泛指为对接人，但这个称呼告诉不了你谁负责付款。
对方可能是品牌员工、代理公司，也可能是 MCN——一单里可能同时出现多个角色。
谈判时必须问清，且三个答案不一定是同一个人：

1. 你代表哪个品牌，所在公司叫什么？
2. 谁确认内容，谁有最终修改权？
3. 谁下单，谁签约，谁付款？

重要信息要能对上，别聊了半个月才发现对接人只能传话、连付款时间都决定不了。
陌生邀约先通过品牌公开联系方式或平台内信息核实身份；**验证码、账号密码绝不给任何人**。

## “水上水下”：先问定义，不要直接回

这两个词没有统一的合同定义，同一个词在不同人嘴里可能是两个意思：

- **合作方式义**：走平台报备合作，还是不走平台私下交易；
- **金额义**：平台订单上显示的金额，以及订单之外另有要求返出的部分费用。

所以对方一问，先反问一句：你说的，是不走平台的合作，还是订单之外另有费用？
如果有费用，要求对方一并说明收款主体、用途和计算方式。
不报备、换词、伪装成普通分享，都不等于没有风险；涉及商业推广，按适用的平台要求和订单完成申报、标识，
不确定的先向平台确认，别用行业黑话代替判断。

## 返点与到账：算清整条链，再看值不值得

- 返点不是平台统一收取的服务费。对方要求返出费用时，要问清：中间方提供了什么服务、由谁付钱、
  合作方是否知情、收款主体是否一致。要求瞒着品牌把钱打给个人的，不要当成“行业都这样”就照办。
- 到账要按链条逐项算，不能只看订单金额：
  约定金额 → 减去返出部分 → 减去平台相关费用、税费、机构分成 → **预计实际到账** →
  再减去道具、交通、场地、外包等支出，对照预计投入时间。
- 结算主体不同，扣费规则不同（例如个人结算与对公结算的安排就不一样），
  不要把“每单都扣固定比例”写成通用公式；以自己结算明细里的税前、税金、税后为准，逐项核对、不重复减。
- 议价优先走平台内协商改价，不要默认用“先高价下单、再私下转钱”解决所有议价问题。
- 钱和时间一起看：一条笔记拍两天、改三天，哪怕报价比上一单高，也未必值得接。

## 报价写法：基础价 + 另议项

没有一条“粉丝数乘系数”的公式能同时适用于手机图文和需要外景、出镜、剪辑的视频。
写法是：**先报一个明确范围内的基础价，再把额外要求单列**：

- **包含**：本账号发布篇数、成片数量、一次大纲确认、约定轮次内的修改；
- **预计发布与保留期限**：写清；
- **不含**：额外平台发布、素材买断、新增拍摄需求；
- **另议**：投流、二改、排竞需求，要求对方给具体范围，确认后单独报价；
- **含税与结算**：含税情况、结算方式、各项费用由谁承担，写清。

其中三个最容易混在一起的概念，必须分开谈：

| 概念 | 谈的是什么 | 要问清 |
|---|---|---|
| 修改轮次 | 改多少次 | 什么算修改：错别字、已确认卖点补充，和“换场景全部重拍”工作量差很多；品牌确认大纲后换产品、换方向，应重新确认费用和时间 |
| 投流与二改 | 使用授权 | 投流是授权品牌为合作内容投放广告；二改是允许对方下载素材、换文案、重新剪辑。问清发布到哪里、使用多久、是否能剪辑、成片是否需你确认，尤其带有人脸和声音的内容 |
| 排竞 | 未来档期占用 | 不能只写“一个月不接竞品”，要具体到哪个品类、从哪一天算起；禁同类清洁产品，和禁所有家居产品，影响完全不同 |

价格和使用范围一起谈：预算少，可以减少交付或缩短授权期限，不必把所有附加要求都塞进同一个价格里。

## 从私信到结算：六步走

1. **先问需求，再给完整报价**：首次回复先要品牌、产品、内容要求、预计发布时间，
   并确认是否走平台报备、是否包含投流、二改或排竞；拿到信息后再一并回复报价和可排档期。
2. **读 Brief，把含糊处问出来**：必拍画面、必须出现的文案、禁用表达、链接或组件、审核时间，
   逐个确认是“建议”还是“验收条件”；参考视频需要你没有的设备或场景，拍摄前就说明；
   品牌提供的功效、排名、销量等材料，要求提供依据；自己没体验过的效果，不写成亲测。
3. **把聊天结果落到订单和书面约定里**：价格、交付、授权、保留期限、回款节点，
   要能在订单或双方确认的文件里找到。另补一个易漏项：样品是赠送还是需要寄回？
   寄回的话运费谁承担、正常拍摄使用造成的变化如何处理？越是需要安装、拆封、长期测试的产品，越要提前谈。
4. **先确认大纲，再投入制作**：大纲写清开头怎么进入、在哪个场景出现产品、展示哪些卖点、结尾怎么收，
   再列关键画面；确认后的版本保留下来，后续新增需求才有共同参照。
5. **审稿通过后，再核对发布版本**：提交时把封面、图片顺序、标题和正文放齐，避免审的是一版、发的是一版；
   发布前再看一次品牌名、型号、活动日期、商业标识和约定组件有没有错；审核通过不等于可以忽略事实错误。
6. **记录交付，跟进结算**：发出后保存链接、发布时间和对应订单，按约定时间反馈数据；
   记录品牌是否投流，不同来源的数据不要混作自然效果；账单出来后核对金额、扣费和收款主体，
   迟迟没结算，拿订单号和已交付记录去沟通。

## 红灯清单：出现这些，先停下来

- **“先发，效果好再给钱”**：按效果付费要把效果统计方式、是否有基础制作费、归因和付款条件写清；
  想接固定费用合作，就不要最后才被改成看数据付款。
- **“就改一点点，你再拍一版”**：先对照已确认的大纲和修改范围；新增要求可以谈，别让一句“小改”变成无限劳动。
- **“素材我们都能用吧？”**：让对方列使用范围；品牌账号转载一篇，和永久用于多个平台广告投放，不能默认是一回事。
- **“先交认证费，后面给你派单”**：不要为得到一单合作先向陌生对接人付款；不提供登录验证码，不扫码登录来历不明的后台。
- **只催留档期、不确认订单和需求**：给出报价有效期和档期保留条件，过期重新确认，别把整周都空在那里。

## 接单前确认单（关键条件没填完，就继续问）

品牌 / 产品 / 型号；对接公司 / 签约与付款主体；合作方式 / 对应订单；
图文或视频 / 数量 / 发布账号；合作金额 / 含税情况；其他费用的用途、收取方和承担方；
大纲与成稿的确认时间；修改轮次 / 重拍条件；发布时间 / 保留期限；
排竞品类 / 起止日期；投流、二改及其他授权的范围和期限；样品归属 / 寄回要求；
验收标准 / 结算时间 / 取消合作的处理。

谈判结束时，这张单子就是第 1 步 Brief 拆解的输入：结算规则、终审流程、授权范围，
直接填进 `templates/brief_intake.md` 的对应项；没谈清的，填进“待确认问题”，不猜、不开写。
