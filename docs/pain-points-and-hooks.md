# 创作者痛点全图 + 强钩子手册

Skill 的每一步都对应一个真实痛点。这份文档是给使用者（和 Agent）看的“为什么”。

## 痛点全图（按接单全程）
| 阶段 | 痛点 | Skill 的解法 |
|---|---|---|
| 每单开始 | **从零起步**：重读 Brief、重对要求、拼命回忆上次打法与驳回原因 | 第 0 步前置检索：开单先调历史经验 |
| 策划 | **没方向、没参照**：选题角度、策划方向临场硬想 | 第 2 步：结合历史有效打法给多组方向 + 钩子拍板 |
| 创意 | **创意枯竭还想爆**：脑子空空，又盼出圈，越想爆越卡壳 | 爆款套路存档复用；五问里的“意外点”强制找新角度 |
| 创作 | **恰饭感平衡**：浓了掉粉，淡了品牌不过 | 创作者档案约束语气；成稿对照人设自检 |
| 创作 | **漏项**：链接位置、福利路径、规格、截止，顺手就漏 | 基础条款 9 项拆解 + 发布前自检 |
| 改稿 | **改稿经验流失**：品牌禁词、法务口径、驳回根源没人记，下单重新磨合 | 复盘单独归档改稿经验，下单动笔前先调取 |
| 发布后 | **经验清零**：一单结束，经验散回聊天记录和脑子 | 第 6 步复盘回存，Case 累积成 SOP |
| 结算 | 报价没谱、催款、税务糊涂账 | 本 Skill 只记录结算规则（本地私有），不代管钱；报价历史可在本地档案自维护 |

## 强钩子手册

### 好钩子的四个零件（至少凑齐三个）
1. **人群点名**：第一句就让目标读者对号入座（“接商单的博主……”）。
2. **痛点共鸣**：说出他正经历的难受（从零起步、没方向、想爆又卡壳）。
3. **价值预告**：看完能带走什么，先承诺（清单 / 方法 / 一套流程）。
4. **悬念缺口**：留一个没说完的东西（“它标出了 3 个最容易漏的点”），中段揭晓、结尾回收。

### 五个可复用公式
| 公式 | 例句（示意） |
|---|---|
| 自指悬念 | “这条帖的第一版，不是我憋出来的，是我的经验库先拆出来的。” |
| 痛点直击 | “接商单最累的从来不是写，是每一单都从零起步，还惦记着要爆。” |
| 反常识 | “我现在写商单，第一件事不是动笔，是先不写。” |
| 利益前置 | “送你一套我每单必过的核对清单，看完直接抄。” |
| 提问代入 | “你有没有过：Brief 在手，脑子空白，截止在催？” |

### 禁用项（写了就改）
- **灾难化夸大**：“翻车、整单白做、血亏、毁号”——博主的真痛点是重复和枯竭，不是出事；夸大会劝退品牌方，也不符合事实。
- **虚假数字**：没统计过就别写“90% 的博主都……”“省一半时间”。
- **开头泄底**：第一段把结论说完，后面没人看——悬念必须留到中段。
- **只喊口号**：“一款神器让你轻松接单！”——没有人群、没有价值、没有证据。

### 自检三问（钩子写完问自己）
1. 不是这个人群的人划走，是这个人群的人会不会停？
2. 第二句结束时，读者知不知道看完能得到什么？
3. 读者想知道的下一个答案，是不是只能往下看才有？
