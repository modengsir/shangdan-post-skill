# 工作流详解（前置流水线）

核心理念：经验在**动笔之前**起作用。每步写清输入、做什么、过关标准。

## 第 0 步 · 调取经验（前置检索）
- 输入：创作者档案、历史 Case / SOP / 改稿经验（记忆层）。
- 做什么：按品牌 + 品类检索，汇总「本单特别注意」：历史有效打法、品牌偏好、驳回教训。
- 过关：清单具体到条，不是“注意红线”这种空话。无记忆层时明确告知并跳过。

## 第 1 步 · 拆解 Brief（基础条款 9 项）
- 输入：Brief 原件（多份合并去重）。
- 做什么：填 `templates/brief_intake.md`：品牌定位 / 交付规格 / 必讲要点 / 内容红线 / 链接位置 / 福利路径 / 发布时间 / 结算规则 / 终审流程。提取不到的进「待确认问题」。
- 过关：必讲要点可逐条打勾；福利路径写到最后一步，读者照着能领到。

## 第 2 步 · 策划方向 + 开篇钩子（拍板）
- 做什么：结合历史有效打法给 3 组方向，每组配 1 个写好的钩子原文 + 1 个推荐。钩子按 `docs/pain-points-and-hooks.md` 的标准自检（人群 / 痛点 / 价值 / 悬念四零件；禁用灾难化夸大与虚假数字）。
- 过关：创作者连方向带钩子一句话敲定；敲定后不回头，除非 Brief 变更。

## 第 3 步 · 内容五问
- 做什么：填 `templates/five_questions.md`，用问句过：钩子够不够抓人？受众准不准？核心价值是什么？有没有意外点？看完能带走什么？
- 过关：五问互相对得上——钩子承诺的，就是结尾交付的。

## 第 4 步 · 成稿
- 做什么：大纲先行（每节标功能），默认一条长帖发完。素材用 `` 占位并汇总清单。
- 过关：必讲要点核销完毕；语气过档案对照，像创作者本人；演示与数据为真实内容或占位，无编造。

## 第 5 步 · 发布前自检（前置质检）
- 做什么：跑 `templates/prepublish_checklist.md`。重点图文一致：正文声称的演示结果必须有真实截图/录屏对应。
- 过关：全绿。有一项红，停下报告，不代发。

## 第 6 步 · 复盘归档
- 做什么：发布 24-72 小时后（或品牌反馈到齐后）填 `templates/case_retro.md`：数据、品牌反馈、有效打法、踩坑，**改稿经验单独成段**（轮次、改动、驳回根源、品牌偏好），最后写一条“下次因此改变什么”的结论，回存记忆层。
- 过关：没有结论的流水账不算复盘；被证伪的旧经验同步纠正/删除。
